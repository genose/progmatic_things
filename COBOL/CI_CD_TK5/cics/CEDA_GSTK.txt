*=============================================================*
* DEFINITIONS CICS - GROUPE GSTK                             *
* Interface : CEDA (CICS Explorer ou ISPF CICS)              *
*                                                             *
* Ordre d'execution :                                        *
*   1. CEDA DEF MAPSET (chaque mapset BMS)                   *
*   2. CEDA DEF PROGRAM (chaque programme COBOL)             *
*   3. CEDA DEF TRANSACTION (chaque code trans)              *
*   4. CEDA INSTALL GROUP(GSTK)                              *
*   5. CEMT SET PROG(GSTKxxx) NEW  (apres recompilation)     *
*=============================================================*

*-------------------------------------------------------------*
* 6. DIAGNOSTIC RAPIDE (si une trans ne fonctionne pas)
*-------------------------------------------------------------*
* Verifier le statut d'un programme :
*   CEMT INQ PROG(GSTK007)
*
* Codes erreur courants dans le message CICS :
*   PGMIDERR   -> programme non defini ou non trouve en LOADLIB
*   MAPFAIL    -> mapset non trouve ou non assemble
*   LENGERR    -> COMMAREA longueur incorrecte
*   NOTOPEN    -> fichier/connexion DB2 non ouverte
*
* Verifier la connexion DB2 :
*   CEMT INQ DB2CONN
*
* Consulter le log CICS (CEMF ou MSGUSR) :
*   CEMT INQ TASK       -> taches en cours
*   CEDF GSTK007        -> mode debogage pas-a-pas (trace EXEC CICS)
