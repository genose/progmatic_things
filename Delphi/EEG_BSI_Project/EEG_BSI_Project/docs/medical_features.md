# Medical Features Implemented

| Feature | Description | Norm Reference |
|----------|--------------|----------------|
| Band Power | Average power within standard EEG frequency bands | AASM/IFCN |
| Asymmetry Index | (Right - Left) / (Right + Left) | Clinical EEG 2020 |
| Suppression Ratio (SR) | Ratio of suppressed low-amplitude periods | BIS Monitoring Norms |
| Spectral Entropy | Measure of signal complexity | Neurophysiol Clin 2018 |
